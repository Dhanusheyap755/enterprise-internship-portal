# Accessibility, Performance & Regression

## Accessibility
- Semantic headings
- Visible labels
- Keyboard focus styles
- `aria-live` status messages
- Clear button names
- Responsive layout

## Performance
- Vite production build
- ETag/static caching
- API result capped at 100 records
- Limited request body
- No heavy UI framework

## Regression
Backend tests cover health, readiness, security headers, validation, application creation, listing and 404 behavior.
